# Home page direction

Visual thesis: a calm local mall companion using warm paper surfaces, deep green accents,
editorial serif headings and promotion photography as the main visual content.

Content plan: orient the shopper to Meridian Mall, offer a discovery query and three
starting ideas, feature two actual seeded offers, expose a readable directory, then invite
another discovery. The logo identifies MallSense; generated posters show fictional tenant offers.

Interaction thesis: a brief staggered entrance establishes the discovery area, the sticky
header gains a subtle shadow during scrolling, and posters/buttons respond on hover.
Native details elements reveal offer terms and destination descriptions. Reduced-motion
preferences disable movement; the page works without JavaScript.

The home page is a Razor view of database-backed response records. Search is explicitly
keyword matching. No fake assistant messages, invented navigation, live stock claims or
fabricated visitor metrics are presented. The demo date is fixed and shown in the page.

Visual assets have been inspected, but page layout has not been browser-verified because
the .NET app has not been compiled or started under the current workspace instruction.
